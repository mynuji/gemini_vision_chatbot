

# 🤖 "보고, 듣고, 말하는 책상 위의 작은 반려 AI" — ESP32-S3 & Gemini Vision 챗봇 제작기

> **한 줄 요약**: 초소형 MCU(ESP32-S3)와 원형 디스플레이, 카메라를 결합해 시각 지능(Gemini Vision)과 실시간 음성 대화(STT/LLM/TTS), 표정 애니메이션, 터치 UI를 갖춘 독립형 데스크탑 AI 어시스턴트를 개발했습니다.

---

## 1. 어디에 필요한가? (기획 배경 및 필요성)

### 💡 기존 AI 스피커의 아쉬움
구글 홈, 아마존 에코, 카카오미니 같은 기존 스마트 스피커들은 편리하지만 명확한 한계가 있었습니다.
1. **시각의 부재**: "내가 들고 있는 이 약 먹는 법 알려줘", "이 부품 이름이 뭐지?"처럼 눈앞의 사물을 직접 보고 물어볼 수 없습니다.
2. **정적인 교감**: 대부분 단순한 LED 링이나 고정 화면으로만 반응하여, 생동감 있는 표정이나 인터랙션이 부족합니다.
3. **자연스러운 대화 흐름(Barge-in) 부족**: AI가 길게 말하고 있을 때 중간에 말을 끊거나 화면을 톡 건드려 다른 질문을 던지는 유연한 턴테이킹(Turn-taking)이 어렵습니다.

### 🎯 이 프로젝트가 해결하고자 한 목표
* **시각과 청각을 아우르는 멀티모달(Multimodal) AI**: 소리로 질문을 듣고, 카메라로 사물을 직접 보며 답변하는 진정한 의미의 비전 어시스턴트.
* **살아있는 인터랙티브 감성**: 원형 LCD 디스플레이를 눈동자 삼아 대기, 경청, 생각, 발화, 졸림 등 감정 상태를 눈 깜빡임 애니메이션으로 표현.
* **책상 위 데스크테리어 & 실용성**: 평소에는 세련된 디지털 시계 및 탁상 캘린더로 작동하다가, 터치나 호출어("Alexa") 한 번으로 즉시 똑똑한 AI로 변신.
* **온디바이스 편의성**: 컴퓨터나 스마트폰 앱 연결 없이, 디바이스의 원형 터치스크린 메뉴에서 직접 Wi-Fi, 음량, 밝기, LLM 엔진을 변경하고 저장.

## 2. 전체 시스템 아키텍처 & 기술 스택

이 시스템은 경량 엣지 하드웨어(**ESP32-S3 클라이언트**)와 고성능 추론 엔진(**Python 기반 중계 서버**)이 저지연 WebSocket으로 긴밀히 협력하는 구조입니다.



### 🛠 하드웨어 구성
* **메인 보드**: Seeed Studio XIAO ESP32-S3 Sense (Dual-Core 240MHz, 8MB PSRAM, 8MB Flash)
* **카메라**: OV2640 200만 화소 센서 (Sense 확장 보드 장착)
* **마이크**: XIAO Sense 온보드 PDM 디지털 마이크
* **오디오 출력**: MAX98357A I2S DAC / Class-D 앰프 + 미니 4Ω 스피커
* **디스플레이 & 터치**: GC9A01 240×240 원형 IPS LCD + CHSC6X/CST816 정전식 터치 센서

## 3. 개발 과정 & 직면했던 기술적 난제들 (Troubleshooting)

임베디드 하드웨어에서 카메라, 오디오, LCD, Wi-Fi를 동시에 구동하면서 고성능 AI와 실시간으로 통신하는 과정은 메모리와 타이밍의 연속적인 싸움이었습니다.

### 1) 내부 SRAM 단편화와 카메라/오디오 DMA 충돌
* **문제**: ESP32-S3는 PSRAM(8MB)이 넉넉하지만, Wi-Fi 네트워크 스택, 오디오 I2S DMA, 카메라 DVP DMA는 **반드시 빠른 내부 SRAM**을 필요로 합니다. 여러 드라이버가 초기화되는 과정에서 내부 SRAM이 단편화되어 카메라 DMA 버퍼 할당 실패로 무한 리부트가 발생하는 현상이 있었습니다.
* **해결**: 드라이버 초기화 순서를 엄격히 재배치했습니다. 가장 큰 연속 DMA 버퍼를 요구하는 카메라를 SRAM 단편화가 발생하기 전에 최우선 할당하고, 오디오 링버퍼와 Wi-Fi 스택의 정적 할당 영역을 튜닝하여 메모리 부족 패닉을 완벽히 해결했습니다.

### 2) NVS Flash 쓰기 시 발생하는 Cache-Disabled Panic
* **문제**: 사용자가 화면 터치로 Wi-Fi나 볼륨 등 설정을 변경하고 저장할 때, NVS(비휘발성 플래시 스토리지)에 커밋하는 순간 ESP32의 SPI 플래시 캐시가 일시적으로 꺼집니다. 이때 실시간 오디오 태스크나 LVGL 그래픽 태스크가 플래시 메모리의 코드를 참조하면서 CPU Panic이 발생했습니다.
* **해결**: 설정 저장 로직을 즉각 실행하지 않고, **내부 SRAM 전용 워커 태스크(Worker Task)**로 NVS 커밋 작업을 비동기 분리(Decoupling)하여, 시스템 캐시 간섭 없이 부드럽게 설정을 영구 저장하도록 수정했습니다.

### 3) 터치 센서 노이즈와 오인식된 대화 끼어들기 방지
* **문제**: 정전식 터치 센서의 하드웨어 INT 핀에 미세한 전기적 노이즈가 유입되면서, AI가 말하는 도중 터치하지도 않았는데 대화가 강제로 중단(False Interrupt)되는 문제가 발생했습니다.
* **해결**: 하드웨어 INT 폴링에만 의존하지 않고, I2C 데이터 레지스터 유효성 검증과 소프트웨어 디바운스(Debounce) 필터를 이중으로 적용하여 정확한 터치 의도만 걸러내도록 안정화했습니다.

### 4) 실시간 턴테이킹(Turn-taking)과 빠른 응답 속도
* 사용자가 말을 끝내자마자 즉각 응답할 수 있도록 **Silero VAD**로 침묵 구간을 밀리초 단위로 정확히 포착하고, 텍스트가 완성되기를 기다리지 않고 Gemini 스트리밍 토큰이 들어오는 즉시 Edge-TTS와 FFmpeg 파이프라인을 통해 조각(Chunk) 단위로 ESP32 스피커에 밀어 넣어 체감 지연 시간을 극적으로 단축했습니다.

## 4. 최종 개발 결과물 & 주요 기능

### 1. 살아 숨 쉬는 표정 UI & 시계 모드
* **감정 상태 시각화**: 대기 중에는 자연스럽게 눈을 깜빡이고(Idle/Blink), 소리를 들을 때는 눈을 크게 뜨며(Listening), 생각할 때는 눈동자를 굴리고(Thinking), 답변할 때는 입 모양 대신 눈 표정이 활발하게 움직입니다(Speaking).
* **탁상 시계 & 절전**: 대화가 끝나고 60초간 상호작용이 없으면, 자동으로 고해상도 아날로그/디지털 시계 화면으로 전환되며 졸린 눈(Sleepy)으로 들어갑니다.

### 2. 눈앞을 직접 보고 대답하는 시각 지능 (Gemini Vision)
* "지금 내가 들고 있는 영양제 어떻게 먹는 건지 읽어줘"라고 말하며 화면을 비추면, 원형 LCD에 실시간 카메라 프리뷰가 표시되고 캡처된 고화질 JPEG 이미지가 Gemini로 전송되어 사물 분석, 텍스트 OCR, 상황 설명이 음성으로 즉각 흘러나옵니다.

### 3. 직관적인 풀 터치 온디바이스 설정 메뉴 (LVGL GUI)
* 기기를 길게 누르면 스마트폰 설정 화면처럼 직관적인 메뉴가 열립니다:
  * 🔊 **볼륨 조절 & 🎤 마이크 게인 조절**
  * ☀️ **화면 밝기 조절**
  * 🌐 **Wi-Fi SSID/비밀번호 변경 및 저장**
  * 🖥️ **중계 서버 IP & 포트 변경**
  * 🧠 **LLM 엔진 선택**: Gemini API, Gemini Realtime API, ChatGPT Realtime, 로컬 LLM 간 손쉬운 전환
  * ⏰ **NTP 서버 및 타임존(Timezone) 설정**

### 4. 대화 끼어들기 (Barge-in)
* AI가 긴 설명을 늘어놓을 때, 화면을 가볍게 톡 터치하거나 다시 말을 시작하면 0.1초 만에 스피커 출력이 중단되고 즉시 사용자의 새 질문을 경청합니다.
